# Trend Signals

Поиск зарождающихся технологических трендов. Команда READY2HYPE, хакатон «Лидеры
цифровой трансформации» 2026, задача №1 (Газпромбанк.Тех).

Пользователь вводит технологическое направление и получает 15 зарождающихся трендов:
чем тренд полезен, кто им занимается, ссылки на первоисточники.

## Установка

Нужен только `uv` — он сам скачает нужную версию Python, создаст окружение и поставит
зависимости точных версий. Системный Python не затрагивается.

```powershell
irm https://astral.sh/uv/install.ps1 | iex
```

Ставится в домашнюю папку; если команда `uv` не находится, открыть новое окно терминала.
На macOS и Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`

```
git clone https://github.com/READY2HYPE/trend-signals-lct2026.git
cd trend-signals-lct2026
uv sync
copy .env.example .env
```

В `.env` вписать почту и ключ OpenAlex. Ключ бесплатный, выдаётся после регистрации на
openalex.org и лежит в настройках профиля; без него суточный лимит выгрузки в десять раз
меньше. Всё это нужно только тем, кто выгружает данные сам.

Запуск через `uv run`, активировать окружение вручную не требуется:

```
uv run python -V
uv run pytest
```

Библиотеки машинного обучения весят гигабайты и нужны не всем, поэтому ставятся отдельно:
`uv sync --extra ml`

## Структура

```
config/   параметры среза данных
data/     подвыборка, агрегаты, индекс, манифест (полная выгрузка — вне репозитория)
docs/     документация
src/      конвейер
scripts/  разовые проверки
```

Сбор корпуса:

```
uv run python scripts/probe_slice.py        замер объёма и полноты полей
uv run python -m src.collect.aggregates     ряды по годам для нормировки
uv run python -m src.collect.openalex       научные работы, продолжается после обрыва
uv run python -m src.collect.arxiv          препринты
uv run python -m src.collect.sample         подвыборка для разработки
uv run python -m src.collect.manifest       манифест; --check сверяет свою выгрузку
uv run python -m src.collect.check          критерии приёмки этапа
```

Бэкенду и фронтенду корпус не нужен: им нужен индекс, он лежит в репозитории.
Образец с настоящими числами — `data/index/sample-index.json`, форма описана
в [контракте](docs/07-контракт.md).
