# Trend Signals

**Поиск зарождающихся технологических трендов.** Команда READY2HYPE,
хакатон «Лидеры цифровой трансформации» 2026.

Задача №1 (Газпромбанк.Тех): сервис автоматизированного сбора и анализа зарождающихся
трендов — слабых сигналов — в научно-технологических отраслях.

Пользователь вводит технологическое направление и получает 15 зарождающихся трендов.
По каждому: чем тренд полезен, кто им занимается, ссылки на первоисточники.
Отдельно — методология и результаты её проверки.

## Быстрый старт

Окружение одинаковое у всех и ставится одной командой. Нужен только `uv` — он сам
скачает нужную версию Python, создаст виртуальное окружение и поставит зависимости
ровно тех версий, что записаны в `uv.lock`.

**Один раз поставить uv:**

```powershell
winget install --id astral-sh.uv
```

Если winget недоступен:

```powershell
irm https://astral.sh/uv/install.ps1 | iex
```

На macOS и Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`

**Дальше в папке проекта:**

```
uv sync
```

Всё. Окружение готово, ставить Python отдельно не нужно — версия зафиксирована в
`.python-version`, и `uv` подтянет её сам, не трогая системную.

Запуск чего-либо — через `uv run`, активировать окружение вручную не требуется:

```
uv run python -c "import pandas; print(pandas.__version__)"
uv run pytest
```

**Библиотеки для машинного обучения** ставятся отдельно, потому что весят гигабайты и
нужны не всем: интерфейс и сбор данных без них обходятся.

```
uv sync --extra ml
```

**Переменные окружения:** скопировать `.env.example` в `.env` и заполнить. Там контактный
адрес для вежливого режима OpenAlex — без него API ограничивает скорость выгрузки.

```
copy .env.example .env
```

**Данные** в репозитории не лежат (см. [docs/06-инфраструктура.md](docs/06-инфраструктура.md)).
В репозитории — конфигурация среза `config/slice.yaml`, агрегаты, манифест и тестовая
подвыборка в `data/sample/`, на которой конвейер запускается за секунды. Полный срез
скачивается из общей папки по ссылке из `data/README.md`.

## Идея в двух абзацах

Список трендов нельзя получить, спросив языковую модель: она называет то, что уже
общеизвестно, то есть по определению не зарождающееся, и не указывает источник.
Поэтому тренды вычисляются по данным: собираются научные публикации, препринты и
патенты, близкие по смыслу работы группируются, и среди групп ищутся те, где начался
рост. Важен не объём, а скорость: как быстро прибавляются работы, когда тема появилась
впервые, сколько независимых организаций её подхватили.

Отдельная часть работы — доказать, что метод работает. Для этого он проверяется на
прошлом: данные обрезаются выбранным годом, алгоритм запускается на них и сверяется
с тем, какие темы выросли позже. Данные после даты среза алгоритму недоступны.
