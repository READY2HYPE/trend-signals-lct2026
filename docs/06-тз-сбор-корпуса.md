# Этап 1 — сбор корпуса

> Черновик к обсуждению. Направление, глубина архива и состав полей пока
> не согласованы.

Пока корпуса нет, ни кластеризацию, ни признаки роста, ни проверку на прошлом запустить
нельзя. От полного текста задания этап не зависит — корпус понадобится при любой
формулировке.

Цель — замороженный срез научных публикаций и препринтов по направлению «искусственный
интеллект» за 2010–2025, с манифестом и воспроизводимой процедурой. Результат не
«скачанные файлы», а набор, про который можно доказать, что он полный и у всех одинаковый.

Патенты, гранты, вакансии и всё, что после выгрузки, — отдельные этапы.

## OpenAlex

Фильтр: подобласть ИИ, 2010–2025, статьи и препринты. Выгрузка курсором, по 200 записей.
Сохраняем идентификатор и DOI, заголовок и аннотацию, год и дату, тип, темы с оценкой,
организации авторов со странами, цитируемость, издание, язык. Список процитированных работ
не берём: он огромный и для наших признаков не нужен.

Четыре вещи, каждая стоит часа отладки:

**Аннотации** отдаются инвертированным индексом (слово → позиции), а не строкой.

**Суточный лимит.** Без ключа 1000 запросов, с бесплатным ключом 10 000, сброс в полночь
UTC. Весь срез — около 7500. Выгрузка обязана переживать упор в лимит: сохранять
набранное, ждать сброса, продолжать.

**Курсорная пагинация.** Смещение по номеру страницы на больших выборках не работает
и молча теряет записи.

**Обрывы неизбежны** — нужны повторные попытки и возобновление с сохранённого курсора.

## arXiv

Препринты опережают журнальную публикацию на 6–18 месяцев. Метаданные забираются по
открытому протоколу OAI-PMH: учётной записи не нужно, лимита нет, страница отдаёт 1300
записей, продолжение по токену.

Разделов три. Информатики мало: машинное обучение заметной долей лежит в `stat.ML`,
сигналы и речь — в `eess`. По одному `cs` сшивка со срезом OpenAlex дала две трети
попаданий, с тремя разделами — три четверти; остаток приходится на физику и математику,
и выгружать их целиком ради него не стоит.

Берём идентификатор, заголовок, аннотацию, категории, авторов, DOI при наличии и **дату
первой версии** — интересует момент первого появления работы, а не последней правки.

Сшивка с научными работами идёт по идентификатору arXiv: DOI проставлен у 2% препринтов.
Работа из двух разделов приходит дважды — это устройство протокола, повторы снимаются
на чтении.

## Хранение

```
data/
  raw/openalex/year=2010/part-000.parquet
  raw/arxiv/set=cs/part-000.parquet
  aggregates/works-by-year.json
  sample/openalex-sample.parquet      20–50 тыс. записей, в репозитории
  manifest.json
```

Разбиение по годам обязательно: срез по дате для проверки на прошлом делается чтением
нужных папок, а не фильтрацией всего объёма. Схема таблицы объявлена в коде одним местом
и по ходу не меняется.

`config/slice.yaml` определяет, какие данные считаются нашими. `manifest.json` говорит,
что реально выгружено — по нему участник проверяет, что у него тот же срез.

## Критерии приёмки

Проверяются командой `uv run python -m src.collect.check`. Этап сдан, когда выполнены все:

1. Записей в срезе — сотни тысяч. Меньше ста тысяч означает неверный фильтр.
2. Доля записей с непустой аннотацией — не ниже 70%.
3. У каждой записи есть год и дата.
4. Дублей по идентификатору нет, записи с общим DOI сведены.
5. Число выгруженных записей по каждому году отличается от агрегата не более чем на 2%.
   Главная проверка: ловит молчаливые потери при пагинации, которые иначе всплывут только
   на графике роста.
6. Контрольные суммы файлов совпадают с манифестом.
7. Подвыборка лежит в репозитории, и на ней конвейер отрабатывает за секунды.
8. Повторный запуск по той же конфигурации даёт тот же результат.

## Чего делать не нужно

Качать полный снимок базы. Подключать пятый источник научных статей — ценность даёт новый
тип свидетельства, а не ещё один поставщик того же. Чистить тексты заранее: векторные
представления работают с текстом как есть. Класть выгрузку в репозиторий.

Дальше — патенты, обязательны по условию задачи. Требования те же: точные даты, глубина
архива, массовая выгрузка.
