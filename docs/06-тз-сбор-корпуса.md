# Этап 1 — сбор корпуса

> Черновик к обсуждению. Направление, глубина архива и состав полей пока
> не согласованы.

Первый этап работ. Всё остальное на него опирается: пока корпуса нет, ни кластеризацию,
ни признаки роста, ни проверку на прошлом запустить нельзя.

Этап не зависит от полного текста задания, которое откроется 15.09: корпус научных работ
понадобится при любой формулировке. Начинать можно немедленно.

## Цель

Получить **замороженный срез** научных публикаций и препринтов по направлению
«искусственный интеллект» за 2010–2025 годы, в едином формате, с манифестом и
воспроизводимой процедурой выгрузки.

Результат этапа — не «скачанные файлы», а набор, про который можно доказать, что он
полный и у всех одинаковый.

## Что входит и что нет

**Входит:** OpenAlex (научные работы), arXiv (препринты), агрегаты по годам для
нормировки, тестовая подвыборка, манифест.

**Не входит** (отдельные этапы): патенты, гранты, вакансии, векторные представления,
кластеризация.

## Источники и поля

### 1. OpenAlex — основной корпус

Фильтр: тематика «искусственный интеллект» и её подобласти, годы 2010–2025, работы
с непустой аннотацией. Выгрузка через API постранично курсором, по 200 записей.

Поля, которые сохраняем:

| Поле | Зачем |
|---|---|
| `id`, `doi` | идентификатор и сшивка с другими источниками |
| `title`, `abstract` | текст для векторных представлений |
| `publication_year`, `publication_date` | временной ряд, срез по дате |
| `type` | отделить статьи от прочего |
| `topics` (идентификатор, название, оценка) | тематическая привязка, переход между областями |
| `authorships` → институты: идентификатор, название, страна | признак распространения |
| `cited_by_count` | вспомогательный вес, **не признак раннего роста** |
| `primary_location` (издание) | вспомогательно |
| `language`, `open_access` | фильтрация и отчётность |

**Не сохраняем** список процитированных работ: он огромный и раздувает объём в разы,
а для наших признаков не нужен.

Подводные камни, каждый стоит часа отладки:

- **Аннотации отдаются инвертированным индексом** (слово → позиции), а не строкой.
  Восстановление в текст — обязательный шаг конвейера, и на нём же проверяется доля
  записей, где аннотации нет вообще.
- **Суточный лимит запросов.** Бесплатно отдаётся 1000 запросов в сутки со сбросом
  в полночь UTC; страница в 200 записей — один запрос. Полный срез требует около 7500
  запросов, то есть восемь суток бесплатной выгрузки. Контактный адрес в запросе нужен
  по-прежнему. Выгрузка обязана переживать упор в лимит: сохранять набранное, ждать
  сброса и продолжать с того же места.
- **Курсорная пагинация**: первый запрос с начальным курсором, дальше — курсор из ответа.
  Смещение по номеру страницы на больших выборках не работает.
- **Обрывы связи неизбежны.** Нужны повторные попытки с нарастающей паузой и
  возобновление с последнего сохранённого курсора, иначе многочасовая выгрузка
  начинается заново после первой сетевой ошибки.
- Тематическая таксономия у источника обновлялась: используем актуальную схему тем,
  а не устаревшие «концепты».

### 2. arXiv — препринты

Метаданные забираются по открытому протоколу OAI-PMH: учётной записи не нужно,
лимита по числу запросов нет, страница отдаёт 1300 записей, продолжение — по токену
из ответа. Разделы выгружаются целиком, отбор по подкатегориям делается уже по
выгруженному: наборы протокола крупные, тоньше он не режет.

Разделов нужно три, а не один. Информатики мало: работы по машинному обучению
заметной долей лежат в `stat.ML`, обработка сигналов и речи — в `eess`. Проверено
сшивкой: по разделу информатики нашлись две трети препринтов из среза OpenAlex,
с добавлением двух других — три четверти. Оставшаяся четверть приходится на физику
и математику; выгружать их целиком ради неё не стоит.

Работа, помеченная сразу в двух разделах, приходит из каждого. Это устройство
протокола, а не ошибка: хранение остаётся пораздельным, потому что так возобновляется
выгрузка, а повторы снимаются на чтении корпуса.

Поля: идентификатор, заголовок, аннотация, категории, авторы, DOI при наличии и
**дата первой версии**. Последнее принципиально: нас интересует момент первого появления
работы, а не дата последней правки.

Препринты — самый ранний сигнал: они опережают журнальную публикацию на 6–18 месяцев.

**Сшивка с научными работами идёт по идентификатору arXiv, а не по DOI.** У препринтов
DOI проставлен примерно у 2%: до 2022 года arXiv их не присваивал. Идентификатор
вытаскивается из ссылок записи OpenAlex и находится у девяти препринтов из десяти.

### 3. Агрегаты для нормировки

Отдельным запросом — сколько всего работ вышло в каждом году: по всему корпусу источника
и по нашему направлению. Это знаменатель, без которого рост темы посчитать нельзя:
публикаций год от года больше, поэтому формально растёт всё.

Сохраняется отдельным маленьким файлом и коммитится в репозиторий.

## Формат хранения

```
data/
  raw/
    openalex/year=2010/part-000.parquet
    openalex/year=2011/...
    arxiv/set=cs/part-000.parquet
    arxiv/set=stat/...
  aggregates/works-by-year.json
  sample/openalex-sample.parquet      # 20–50 тыс. записей, лежит в репозитории
  manifest.json
```

Формат — parquet со сжатием: он компактнее JSON в несколько раз и читается частями.
Разбиение по годам обязательно: срез по дате для проверки на прошлом должен делаться
чтением нужных папок, а не фильтрацией всего объёма.

Схема таблицы фиксируется в коде одним объявлением и не меняется по ходу: расхождение
схем между участниками — источник ошибок, которые обнаруживаются в последний день.

## Конфигурация и манифест

**`config/slice.yaml`** — описание среза: направление, диапазон лет, фильтры, версия
источника, размер страницы, пути. Файл в репозитории, и именно он определяет, какие
данные считаются нашими.

**`data/manifest.json`** — что реально выгружено:

- идентификатор среза (направление, годы, дата выгрузки);
- список файлов с размерами и контрольными суммами;
- число записей по годам;
- параметры запроса и версия кода, которым выгружали.

Манифест коммитится в репозиторий. По нему любой участник проверяет, что у него тот же
самый срез: расхождение в данных — самая трудноуловимая причина «у меня работает,
у тебя нет».

## Критерии приёмки

Этап считается сданным, когда выполнены **все** пункты:

1. Записей в срезе — сотни тысяч. Если получилось меньше ста тысяч, фильтр составлен
   неверно, и это нужно обсудить, а не пытаться работать дальше.
2. Доля записей с непустой аннотацией — не ниже 70%. Замер по пробному фильтру дал
   73%, причём доля растёт от года к году: 60% в 2016, 83% в 2023.
3. У каждой записи есть год и дата публикации.
4. Дублей по идентификатору нет; записи, совпадающие по DOI, сведены.
5. **Полнота проверена по агрегатам**: число выгруженных записей по каждому году
   отличается от агрегата, полученного отдельным запросом, не более чем на 2%.
   Это главная проверка — она ловит молчаливые потери при пагинации, которые иначе
   всплывут только на графике роста.
6. Контрольные суммы файлов совпадают с манифестом.
7. Подвыборка лежит в репозитории, и на ней конвейер отрабатывает за секунды.
8. Повторный запуск по той же конфигурации даёт тот же результат.

## Порядок работ

| Шаг | Ожидаемое время |
|---|---|
| Подобрать фильтр по направлению, проверить объём выдачи агрегатом | 1–2 часа |
| Написать выгрузку с курсором, повторными попытками и возобновлением | половина дня |
| Восстановление аннотаций, приведение к схеме, запись в parquet | несколько часов |
| Полная выгрузка (идёт фоном) | восемь суток бесплатно либо несколько часов платно |
| Метаданные препринтов, сшивка по DOI | 2–3 часа |
| Агрегаты, подвыборка, манифест, проверки приёмки | 2–3 часа |

Итого один-два рабочих дня, из которых значительная часть — ожидание.

## Чего делать не нужно

- **Качать полный снимок базы** (сотни гигабайт, дни загрузки). Нам нужен срез по одному
  направлению; полный корпус не даёт ничего, кроме занятого диска.
- Подключать пятый источник научных статей. Ценность даёт новый **тип** свидетельства,
  а не ещё один поставщик того же самого.
- Чистить и лемматизировать тексты заранее. Векторные представления работают с текстом
  как есть; преждевременная обработка только портит.
- Класть выгрузку в репозиторий. Туда идут конфигурация, манифест, агрегаты и подвыборка.
