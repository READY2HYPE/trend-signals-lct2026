# Данные

## Как выбираем источники

Не «максимум источников», а покрытие типов свидетельств. Каждый источник стоит примерно
одинаково, а пользы приносит тем меньше, чем больше дублирует подключённый: второй
поставщик научных статей почти ничего не добавляет. Двадцать наполовину подключённых
источников дают дашборд без проверки методологии — худший из возможных результатов.

Идея идёт по цепочке зрелости: препринт → статья → грант → патент → код → выручка → найм.
Ценность источника в том, какую стадию он закрывает. Берём, если у записей есть точная
дата, архив глубже десяти лет, выгрузка массовая, а тип свидетельства новый.

Роли у данных разные. Ряды для детектора требуют глубокого архива, эталон для проверки —
независимого списка прорывов с годами, свежий поток для демонстрации живёт актуальностью.
Вакансии, например, сильный канал: наём под технологию означает вложенные деньги. Но
открытые API кадровых площадок архива не отдают, поэтому в ретроспективной проверке они
не участвуют — знать это надо до написания коннектора.

## Что подключено и что дальше

| Стадия | Источник | Состояние |
|---|---|---|
| препринт | arXiv, разделы cs, stat, eess | выгружен |
| наука | OpenAlex, подобласть ИИ | выгружен |

Берём срез по направлению за 15 лет, а не корпус целиком: полтора миллиона работ
и несколько часов против сотен гигабайт и дней у полного снапшота. Знаменатель для
нормировки берётся отдельным агрегирующим запросом.

## Что показал замер

По срезу «искусственный интеллект» за 2010–2025, статьи и препринты: 1 509 857 записей,
с аннотацией 1 106 825. Повторяется командой `uv run python scripts/probe_slice.py`,
ряды по годам — в `data/aggregates/works-by-year.json`.

**Полнота аннотаций растёт от года к году**: 60% в 2016, 70% в 2019, 83% в 2023. Отбор
записей по наличию аннотации теряет в старых годах вчетверо больше, чем в свежих, и рост
появляется у всех тем разом — растёт не наука, а полнота метаданных. Отсюда правило про
одинаковую фильтрацию числителя и знаменателя.

**Общий счётчик записей за 2025 год как знаменатель непригоден**: он выше 2024 на 37%, но
две трети прироста дают наборы данных и записи «прочее», а не публикации. Нормируем по
ряду статей и препринтов, он растёт ровно.

**Аффилиации указаны примерно у половины записей** (54%), поэтому признак распространения
считается по этой половине.

**Тематическая привязка вероятностная**: у 12% записей уверенность ниже 0,5, в подобласть
попадают смежные работы. Порог задан в `config/slice.yaml`.

**Даты неточны у пятой части записей**: день неизвестен, проставлено 1 января. Годовые
ряды строятся, помесячные — нет.

**Препринты сшиваются по идентификатору arXiv, а не по DOI**: DOI проставлен у 2%
препринтов, до 2022 года arXiv их не присваивал. Идентификатор извлекается из ссылок
записи и находится у девяти из десяти.

**Подобласть шире своего названия.** Внутри рубрики «Artificial Intelligence» у источника
77 тем, и пятая часть корпуса к ИИ прямого отношения не имеет: 9,1% — педагогика,
кадровые исследования, языкознание (проверено чтением заголовков: «Impact of Employees'
Workplace Environment on Employees' Performance»), ещё 12,1% — смежная информатика,
квантовые вычисления и криптография. При этом темы вроде геологии или солнечной
энергетики выбрасывать нельзя: под ними лежит машинное обучение для дистанционного
зондирования и прогноза выработки, то есть применение ИИ в других отраслях — как раз
то, из чего виден переход между областями.

Отсюда две вещи. Корпус нельзя называть «полтора миллиона работ по ИИ» — честно
«в подобласти ИИ по классификации источника». И отбор подкорпуса под запрос должен
идти по смыслу: посторонние темы отсекает он, а не фильтр выгрузки.

## Срез фиксируется

Выгрузка сохраняется файлами и дальше не меняется. Проверка на прошлом имеет смысл только
на неизменном срезе: если корпус течёт, вчерашние результаты сегодня не повторяются.

**Ряды в `data/aggregates/works-by-year.json` — часть замороженного среза, а не справка.**
По ним проверяется полнота выгрузки, поэтому пересчитывать их из API нельзя: источник
дописывает записи задним числом, и через две недели расхождение с выгрузкой выросло
с нуля до 1,91% при пороге приёмки 2%. Выглядело бы это как испорченный корпус, хотя
сдвинулся эталон. Команда `aggregates` по умолчанию их не трогает и обновляет только ряд
`slice_embeddable`, который считается по самой выгрузке; перезапрос — явным `--force`.
И сервис на защите не должен ходить в интернет — недоступность внешнего API в этот момент
означает провал показа. Как срез хранится и сверяется — [05-разработка.md](05-разработка.md).

## Эталон

Без внешнего списка проверка вырождается в подгонку: метод выдал двадцать тем, и мы сами
решаем, какие «попали». Берём **MIT Technology Review, «10 Breakthrough Technologies»** —
выходит ежегодно с 2001 года, около 250 записей с привязкой к году, открыт и независим.
Плюс список негативных контролей.

Отчёты закрытых исследовательских компаний как эталон не годятся: они платные, архивы по
годам официально не публикуются, а пересказы из вторых рук для измерения не подходят.
