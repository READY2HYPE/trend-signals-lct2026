# Данные

## Принцип отбора: не «максимум источников», а покрытие типов свидетельств

Каждый источник стоит одинаково — коннектор, нормализация, устранение дублей, сведение
названий организаций и терминов к общему словарю. А пользы приносит тем меньше, чем
больше дублирует уже подключённый: второй поставщик научных статей почти ничего не
добавляет. Двадцать наполовину подключённых источников дают дашборд без проверки
методологии, то есть худший из возможных результатов.

Идея проходит по цепочке зрелости: **препринт → статья → грант → патент → код → выручка
→ найм**. Ценность источника определяется тем, какую стадию он закрывает.

Источник берётся, только если проходит **все четыре условия**:

1. у записи есть точная дата — без неё нет временного ряда и нечего дифференцировать;
2. архив не меньше 10 лет — иначе на нём не запускается проверка с обрезкой по 2021 году;
3. массовая выгрузка (дамп или API с курсором), а не постраничный обход — сбор не должен
   съесть срок разработки;
4. это новый **тип** свидетельства, а не ещё один поставщик того же самого.

## Три роли данных, которые нельзя смешивать

| Роль | Зачем | Требования |
|---|---|---|
| **A. Ряды для детектора** | считать динамику и признаки роста | глубокий архив, точные даты |
| **B. Эталон для проверки** | независимо подтвердить, что метод находит настоящее | список признанных прорывов с годами |
| **C. Свежий поток для демонстрации** | показать сигнал «на сегодня» | живость важнее глубины |

Разделение существенное. Например, **вакансии** — сильный канал: наём под технологию
означает, что в неё уже вкладывают деньги. Но открытые API кадровых площадок отдают
только актуальные вакансии, исторического архива нет. Значит вакансии работают в роли C
и в ретроспективной проверке не участвуют. Это нужно знать до написания коннектора.

## Состав по стадиям

| Стадия | Источник | Почему он |
|---|---|---|
| препринт | arXiv (открытые метаданные) | опережает журнальную публикацию на 6–18 месяцев |
| наука | OpenAlex (открытая лицензия) | сотни миллионов работ, готовые сведения об авторах, институтах и странах — «распространение» и «переход между областями» считаются напрямую |
| деньги в науку | базы грантов (NSF, CORDIS) | грант приходит раньше статьи |
| патент | открытые патентные базы | переход к прикладной стадии |
| код | архив событий GitHub | ранний сигнал в ИТ, полностью датирован |
| коммерциализация | раскрытия компаний | упоминание технологии в отчётности означает, что она дошла до бизнеса |

Приоритет: первые две строки обязательны, патенты обязательны по условию задачи,
остальное подключается по мере готовности.

## Объём выгрузки

Берём **срез по направлению за 15 лет**, а не корпус целиком. Для одного направления это
порядка миллиона работ — выгружается через API курсором за несколько часов и занимает
гигабайты. Полный снапшот OpenAlex весит сотни гигабайт в сжатом виде и требует дней
загрузки; для одного направления он не нужен.

Знаменатель для нормировки — сколько всего работ вышло в каждом году — берётся отдельным
агрегирующим запросом, скачивать ради него весь корпус тоже не нужно.

Часть открытых наборов (архив событий GitHub, патентные базы) доступна через облачные
хранилища с оплатой по объёму запросов. Подключать осознанно, с ограничением выборки.

## Срез фиксируется

Выгрузка сохраняется файлами и дальше не меняется. Две причины:

1. **Воспроизводимость.** Проверка на прошлом имеет смысл только на неизменном срезе:
   если корпус течёт, вчерашние результаты сегодня не повторяются.
2. **Надёжность демонстрации.** Сервис на защите не должен ходить в интернет: любая
   недоступность внешнего API в этот момент означает провал показа.

Как срез хранится и передаётся внутри команды — [06-инфраструктура.md](06-инфраструктура.md).

## Эталон для проверки

Без внешнего списка ретроспективная проверка вырождается в подгонку: метод выдал двадцать
тем, и мы сами решаем, какие «попали».

- **MIT Technology Review, «10 Breakthrough Technologies»** — публикуется ежегодно
  с 2001 года, около 250 записей с привязкой к году. Открытый и независимый источник.
- **Негативные контроли** — темы, которые были громкими и не выросли.

Отраслевые аналитические отчёты закрытых исследовательских компаний в качестве эталона
не используются: они платные, архивы по годам официально не публикуются, а пересказы
из вторых рук не годятся для измерения.
