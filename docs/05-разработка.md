# Разработка

## Git

Одна основная ветка, короткие ветки под задачи, слияние по готовности. Данные и артефакты
тяжелее мегабайта не коммитятся, за этим следит `.gitignore`. Перед слиянием конвейер
прогоняется на подвыборке — это секунды.

## Почему данные лежат отдельно

GitHub отклоняет файлы больше 100 МБ, бесплатный LFS даёт гигабайт. Корпус в эти рамки не
помещается и не должен: git хранит все версии файла, поэтому выгрузка, положенная туда
однажды, останется в истории навсегда и утяжелит клонирование для всех.

| Что | Размер |
|---|---|
| Срез за 15 лет, ~1,5 млн записей | 500–600 МБ |
| Препринты arXiv, 1,1 млн записей | 640 МБ |
| Векторные представления того же объёма | ~1,5 ГБ |
| Готовый индекс: кластеры, признаки, карточки | единицы мегабайт |
| Тестовая подвыборка | 10–30 МБ |

Отсюда главное следствие: **тяжёлое считается один раз, команда работает с лёгким.**
Интерфейсу и API корпус не нужен вообще — им нужен индекс, а он мегабайтный и лежит
в репозитории.

Форматы разные по слоям. Корпус — parquet: он вчетверо компактнее JSON и отдаёт одну
колонку, не разбирая файл целиком (25 тысяч записей — 9 МБ против 42 МБ, чтение колонки
за 1 мс против 590). Агрегаты, манифест и индекс — JSON: они мелкие, их читают глазами,
а индекс к тому же уходит по сети.

Полная выгрузка хранится в общей папке, порядок получения — в
[../data/README.md](../data/README.md), сверка между участниками по контрольным суммам
из манифеста.

## Тестирование и воспроизводимость

Конвейер запускается в режиме выборки на данных из `data/sample/` за секунды — это
прогоняется при каждом изменении. Полный прогон делает один человек и кладёт результат
в репозиторий как индекс. Везде, где есть случайность (снижение размерности,
кластеризация), значения генератора фиксируются: иначе два запуска дают разные кластеры
и сравнивать нечего.

Цель — один скрипт, который из конфигурации и среза получает итоговые цифры. Если он
проходит от начала до конца на чужой машине, решение можно защищать. Это требование не
про аккуратность, а про суть задачи: проверка на прошлом имеет смысл только на неизменном
срезе.

## Деньги

Почти всё бесплатно, но одно место стоит знать.

**Доступ к API OpenAlex** без ключа даёт 1000 запросов в сутки, с бесплатным ключом
(регистрация на openalex.org, ключ в настройках профиля) — 10 000. Одна страница выгрузки
это 200 записей, весь наш срез — около 7500 запросов, то есть укладывается в один день
бесплатно. Дальше платно, по 0,0001 доллара за запрос. Ключ кладётся в `.env`. Обходить
лимит подменой почты не станем: источник открытый и лежит в основе всей работы.

Хранилища хватит бесплатного облачного. Представления для миллиона коротких текстов
считаются на видеокарте час-два, на процессоре ноутбука за ночь — бесплатные тетради
с доступом к видеокарте закрывают это целиком. Остальные источники открыты.
