# Разработка

## Git

Одна основная ветка, короткие ветки под задачи, слияние по готовности. Пять человек за
две недели без этого гарантированно затрут друг другу правки.

Правила, которых достаточно:

- данные и артефакты тяжелее мегабайта не коммитятся, за этим следит `.gitignore`;
- имена конфигураций и артефактов содержат версию среза, чтобы результаты разных
  прогонов не путались;
- перед слиянием конвейер прогоняется на подвыборке.

## Почему данные лежат отдельно

GitHub отклоняет файлы больше 100 МБ и предупреждает уже с 50 МБ; бесплатный LFS даёт
1 ГБ хранилища и столько же трафика в месяц. Корпус в эти рамки не помещается.

И не должен: git хранит все версии файла, поэтому выгрузка, положенная туда однажды,
останется в истории навсегда и утяжелит клонирование для всех.

| Что | Размер |
|---|---|
| Срез по направлению за 15 лет, ~1 млн записей | 300–500 МБ в parquet |
| Векторные представления того же объёма | ~1,5 ГБ |
| Готовый индекс: кластеры, признаки, топ, карточки | единицы мегабайт |
| Тестовая подвыборка | 10–30 МБ |

Отсюда главное следствие: **тяжёлое считается один раз, команда работает с лёгким.**
Интерфейсу и API корпус не нужен вообще — им нужен индекс, а он мегабайтный и лежит
в репозитории.

Полная выгрузка хранится в общей папке, порядок получения — в [../data/README.md](../data/README.md).

## Тестирование

- **На подвыборке.** Конвейер запускается в режиме выборки на данных из `data/sample/`
  за секунды. Это то, что прогоняется при каждом изменении.
- **Полный прогон** делает один человек и кладёт результат в репозиторий как индекс.
- **Фиксированные значения генератора случайных чисел** везде, где есть случайность
  (снижение размерности, кластеризация). Иначе два запуска дают разные кластеры
  и сравнивать нечего.

## Воспроизводимость

Один скрипт, который из конфигурации и среза получает итоговые цифры. Если он проходит
от начала до конца на чужой машине, решение можно защищать.

Это требование не про аккуратность, а про суть задачи: проверка методологии на прошлом
имеет смысл только на неизменном срезе. Если корпус течёт, вчерашние результаты сегодня
не повторяются и проверять нечего.

Сверка среза между участниками — по контрольным суммам из манифеста. Расхождение
в данных даёт самую трудноуловимую ошибку: «у меня работает, у тебя нет».

## Что может понадобиться купить

Ничего обязательного.

- **Хранилище** — бесплатных облачных 15 ГБ достаточно. Объектное хранилище (порядка 2 ₽
  за гигабайт в месяц) имеет смысл только ради удобной синхронизации.
- **Вычисления** — представления для миллиона коротких текстов считаются на видеокарте
  час-два, на процессоре ноутбука за ночь. Бесплатные тетради с доступом к видеокарте
  закрывают эту задачу целиком.
- **Данные** — все используемые источники открыты.

Единственное место, где деньги могут утечь незаметно, — облачные выгрузки больших
наборов с оплатой по объёму запроса. Их проще ограничить выборкой, чем оплачивать.
