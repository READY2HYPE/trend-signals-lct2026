# Данные

Выгрузка в репозитории не хранится: файл больше 100 МБ GitHub не принимает, а корпус
занимает сотни мегабайт. Подробности и порядок величин —
[../docs/06-инфраструктура.md](../docs/06-инфраструктура.md).

## Что лежит здесь

| Путь | Что | В репозитории |
|---|---|---|
| `sample/` | подвыборка 20–50 тыс. записей для тестов и разработки | да |
| `aggregates/` | число работ по годам — знаменатель для нормировки | да |
| `manifest.json` | состав среза: файлы, размеры, контрольные суммы, счётчики по годам | да |
| `raw/` | полная выгрузка | нет |

## Как получить полный срез

1. Скачать архив из общей папки: **ссылка будет здесь после первой выгрузки**
2. Распаковать в `data/raw/`
3. Проверить, что совпадает с `manifest.json` — контрольные суммы должны сойтись

Расхождение в данных между участниками — самая трудноуловимая причина «у меня работает,
у тебя нет». Поэтому сверка по манифесту обязательна, а не по желанию.

Срез **заморожен**: после выгрузки он не меняется. Иначе проверка методологии на прошлом
теряет смысл — вчерашние результаты перестают воспроизводиться.
