# Данные

Полная выгрузка в репозитории не хранится: GitHub не принимает файлы больше 100 МБ,
а корпус занимает больше гигабайта. Порядок величин —
[../docs/05-разработка.md](../docs/05-разработка.md).

| Путь | Что | В репозитории |
|---|---|---|
| `index/` | готовый индекс: кластеры, признаки, карточки | да |
| `sample/` | подвыборка 20–50 тыс. записей для разработки | да |
| `aggregates/` | число работ по годам, знаменатель для нормировки | да |
| `manifest.json` | состав среза: файлы, размеры, контрольные суммы | да |
| `raw/` | полная выгрузка | нет |

**Бэкенду и фронтенду нужен только `index/`.** Корпус им не требуется вообще.

## Как получить полный срез

Скачать архив из общей папки (ссылка появится здесь после первой выгрузки), распаковать
в `data/raw/` и сверить: `uv run python -m src.collect.manifest --check`. Контрольные
суммы должны сойтись — расхождение в данных даёт самую трудноуловимую ошибку «у меня
работает, у тебя нет».

Либо выгрузить самому теми же командами, что в README: они продолжаются после обрыва
и упора в суточный лимит.

Срез заморожен: после выгрузки он не меняется. Иначе проверка методологии на прошлом
теряет смысл — вчерашние результаты перестают воспроизводиться.
